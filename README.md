# Adriatica Real Estate — Property Listing Platform

Modern real estate web application for browsing, filtering, and managing property listings.

## Features

- Property listings with filtering and pagination
- Admin dashboard (Firebase Auth protected)
- Image hosting via Cloudinary
- WhatsApp contact integration
- Fully responsive design

## Tech

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Firebase (Auth + Firestore)
- Cloudinary
