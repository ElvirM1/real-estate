# Adriatica Real Estate

A responsive real estate website for discovering properties in Kosovo and contacting the agency.

## Features

- Browse property listings
- Filter and paginate property results
- Admin dashboard with Firebase Authentication
- Property image management with Cloudinary
- WhatsApp contact integration
- Responsive layout for desktop and mobile

## Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Backend services:** Firebase Authentication and Cloud Firestore
- **Image hosting:** Cloudinary

## Live Website

[adriaticarealestate.com](https://www.adriaticarealestate.com/)

## Getting Started

Clone the repository and install dependencies:

```bash
git clone https://github.com/ElvirM1/real-estate.git
cd real-estate
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production Build

```bash
npm run build
npm start
```
